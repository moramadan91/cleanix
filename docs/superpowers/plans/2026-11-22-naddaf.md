# Naddaf (نضّف) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. You are running in a terminal that renders Arabic badly: write ALL reports, commit messages and code comments in English. Arabic appears only inside the String Catalog.

**Goal:** A native macOS cleaner (clean caches, trash, forgotten files, duplicates, apps+leftovers, disk map, shredder, maintenance) with Arabic/English UI in a Liquid Glass design.

**Architecture:** Swift package `NaddafCore` holds all scanning/cleaning logic with no UI and is fully unit-tested on temp directories. A SwiftUI executable target `Naddaf` renders it and is wrapped into a `.app` by `scripts/bundle.sh`. Every deletion goes through one `Cleaner` guarded by a `PathPolicy` allowlist.

**Tech Stack:** Swift 6.4, SwiftUI (`glassEffect`), Swift Testing or XCTest, Xcode 27.2, macOS 27. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-22-mac-cleaner-design.md`

## Global Constraints
- Work only inside `/Users/mohamedramadan/mac-cleaner/`. Run `git init` there in Task 1; commit after every task.
- Deployment target: macOS 27 only. App is non-sandboxed. No Mac App Store.
- No third-party dependencies. Apple frameworks only.
- Tests use temp directories only. NEVER run any cleaner, shredder or maintenance code against the real home folder or real system paths.
- Deletion happens only through `Cleaner`, and only for URLs that `PathPolicy.isAllowed` accepts (allowlist, never blocklist).
- UI strings exist in Arabic and English via one String Catalog; layout direction follows the language (RTL for Arabic).
- Colors: background `#14101C`, single UI accent `#FFB04A`, secondary `#FF6B8A` ONLY in the animated background, never on buttons or text.
- No names, colors, icons or copy from CleanMyMac. Feature names: Sweep, Trash Bins, Forgotten, Disk Map, Remover, Shredder, Maintenance, Duplicates, Login Items.
- Emptying the system Trash is permanent and requires an explicit separate confirmation flag.
- After each task write `reports/task-NN.md` (max 15 lines: what was done, tail of test output, deviations from this plan, open questions) and stop to let the human review when a task says STOP.

## Review Focus
1. Symlink inside an allowed root pointing outside it: must be refused, never followed (Task 2).
2. File names with Arabic, spaces and NFD/NFC-different Unicode: scanned and cleaned correctly, no crash (Task 4).
3. Permission-denied or vanished file mid-clean: recorded in `failed`, rest continues (Task 3).
4. Hardlinked files and zero-byte files: never reported as duplicates (Task 7).
5. Cancelling a long scan: returns promptly with no partial deletion (Task 6).
